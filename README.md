**Field notes.** Most specimens in this collection were first spotted in the wild at the office: a report rebuilt by hand every Monday, or a question that went unasked because answering it needed a specialist and a query. Left alone, these creatures multiply. Each one here was caught, studied and tamed into a tool the whole team can open in a browser.

**How the workshop runs.** I'm the architect, and Mr. AI Carpenter does the carpentry. I decide what to build, how the analysis should work and what every screen says; the code is written with generative AI under my direction.
